# Olivia Arcana — The Fold

One developed card-back direction, based on the earlier fan design.

## Drawing

Two opposing fans frame a slender olive sprig. Each fan is built from thirteen ordered cubic curves, with five selected gold crests and one continuous rim. The emblem and gold curves use the same material layer. The two fan families share proportions; the olive retains its directional silhouette.

The ornament is native vector geometry. This version contains no generated image plates, marble texture, celestial filler or embedded raster artwork. Its blue flutes, fine grain and gold lighting are SVG presentation effects. The flat drawing shows the underlying colour and contour system.

## Material direction

Deep blue printed stock, muted gold foil and restrained embossing. Artwork uses a 7:12 ratio. Separation files are set to a nominal 70 × 120 mm; bleed, cutting tolerances, minimum foil line/gap and emboss depth must be agreed with the chosen printer before manufacture. The SVG lighting is a digital interpretation, not a verified physical sample.

This is a local artwork proposal. The hero and live website have not been changed. Previous explorations remain available in the earlier-directions gallery.
