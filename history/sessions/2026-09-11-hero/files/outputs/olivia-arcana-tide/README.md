# The Tide Opens — Olivia Arcana

Open **index.html**. Scroll down and back up, or choose **Begin the journey** to watch the roughly 12.5-second opening. **Skip the opening** takes you straight to the reading entrance. **Pause motion** and **Replay the opening** are included.

The HTML embeds its images, fonts, styling and animation. It opens locally without installing anything. The links to the existing Oracle and Daily Card use the internet.

- **storyboard.html** — the visual concept, three acts, references and motion preview.
- **DESIGN_SYSTEM.md** — design decisions and implementation instructions for Claude.
- **ASSETS.md** — original artwork registration, generated sanctuary, and provenance.
- **QA.md** — checks completed and remaining physical-device verification.
- **modular.html**, **style.css**, **app.js**, **world.glsl**, **assets/** — separate implementation files. Use a local web server while editing this version.
- **mockups/** — desktop and mobile stills, reading entrance, storyboard and `the-tide-opens.mp4`.

The new effect is a continuous passage: original Olivia approaches through water, her wake rises into a huge moonlit opening, and the view passes into a second sanctuary before reaching the reading entrance. Olivia’s color comes from the original photograph at every point. No regenerated portrait is swapped in.

Reading topics demonstrate interface behavior. They do not generate a reading or transfer the selected question to the existing website. Production files and deployment were not changed by this concept build.
