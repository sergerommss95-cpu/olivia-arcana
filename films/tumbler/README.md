# TUMBLER

A ~27-second cinematic short about a bank robbery, told entirely by objects, with no humans. Every
model, material, light and camera move is generated by Python driving headless **Blender 5.2**
(Cycles on CPU). The edit, grade, transitions and sound mix are code too (numpy + ffmpeg).

Method and style follow Leon Lin's open-source short ESCAPEMENT
([github.com/Leonxlnx/escapement](https://github.com/Leonxlnx/escapement), MIT): one production
bible, a shared procedural toolkit, one script per act, stills as the feedback loop, and a code-only
post pipeline. None of its scenes or assets are reused.

## The film

Black → a light sweep across a safe's combination dial; it whips round and stops dead on 40 →
inside the lock the brass tumbler wheels line up their gates on the beat → the fence drops, the
bolt slams, whip-pan → a 3 m round vault door; the hand wheel spins → the radial chrome bolts
retract on three beats in near-silence → the door swings open and the music drops as warm light
pours out → FPV through a red laser grid toward the gold → the deposit-box doors fly open in a
wave → macro across stamped gold bars → pull back on the grid of boxes, which becomes the lit
window grid of a tower at night → the getaway car bursts onto a wet street under police light,
banknotes in its wake → a note flies into the lens → its guilloche rosette dissolves into the
dial → title.

## Layout

```
BRIEF.md          production bible (story, transitions, look rules, technical rules)
shotlist.json     16 shots: id, script, cut length, handles
lib/common.py     toolkit: Cycles setup, materials (machined/engine-turned metal, brass, wet concrete, paint...),
                  primitives, text, camera rigs, shake, lights, CLI (stills / anim)
lib/lock.py       combination dial, guilloche shader, engine-turned steel, tumbler wheel pack
lib/vault.py      round vault door, antechamber, deposit-box walls, gold bars, laser beams
lib/note.py       the fictional "Tumbler Reserve Note" (procedural intaglio print)
lib/city.py       night street, facades, getaway car (Act IV)
shots/act*.py     one script per act; `--shot ID` builds the scene and renders that shot
tools/rb.py       runs Blender headless behind a global lock (one render at a time)
tools/render_queue.py  renders final frames in small chunks (only the frames the edit uses)
tools/edit.py     conform, transitions (cut / whip / luma dissolve / dissolve), grade, halation, grain, letterbox
tools/mix.py      music + SFX from edit/cues.json, timed per shot/frame on the 120 BPM grid
tools/assemble.py edit -> mix -> out/TUMBLER.mp4 (+ phone copy)
tools/exposure_check.py, tools/sheet.py   QC for stills
audio/manifest.json    every sound: source URL, license (files are not committed)
edit/edl.json, edit/cues.json          the edit decision list and the sound cue sheet
notes/            per-act build notes
```

## Reproduce

Requirements: Linux/macOS/Windows with Blender 5.2 (`blender` on PATH or `BLENDER=/path/to/blender`),
ffmpeg, Python 3 with numpy and Pillow.

```bash
cd films/tumbler
python3 tools/rb.py shots/act1_lock.py -- --shot 1A --stills 10,30 --pct 50     # test stills -> tests/
python3 tools/fetch_audio.py                                                    # music + SFX (Mixkit)
TUMBLER_ADAPTIVE=0.06 python3 tools/render_queue.py --samples 20 --pct 88      # all shots (hours on CPU)
python3 tools/assemble.py                                                       # -> out/TUMBLER.mp4
```

Render cost on a 4-core CPU with no GPU: 10–35 s per frame at 1126x472 (upscaled to 1920x804 in the
edit). On a machine with a GPU, set Cycles to GPU in `common.setup_render` and raise samples.
