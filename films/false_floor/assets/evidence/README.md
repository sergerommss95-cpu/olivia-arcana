# Evidence photos: FALSE FLOOR, Case No. 02

Free-licensed photos from Wikimedia Commons for the `E_*` evidence slots and spares in `script/EP_v3_PLAN.md`. Each file's licence was read from the Commons file page metadata (extmetadata `LicenseShortName`) at download time. Full records are in `credits.json`; a visual overview is in `contact_sheet.jpg`.

**Rules followed:** only CC0, Public domain, CC BY or CC BY-SA; no press or agency photos; no identifiable faces (places, buildings, streets and objects only). Files with small background figures are flagged below.

**Resolution:** Wikimedia rate-limits original-file downloads for automated clients and asks for its standard thumbnail sizes instead, so files were saved as the 3840 px (originals > 3840 px) or 1920 px (originals ≤ 3840 px) standard rendering. `width`/`height` in credits.json are the original's size; `downloaded_width`/`downloaded_height` are the saved file's. A higher-resolution original can be fetched later from `page_url` if needed.

**Licence duties:** show the on-screen credit line (bottom-left, Inter 18 px, 70 % white, per the plan) while the photo is on screen, and list every credit with its licence link in the YouTube description. CC BY / CC BY-SA require attribution. CC BY-SA (share-alike) means the graded or displaced version of that photo is an adaptation and should be offered under the same licence; say so in the description (e.g. 'Adapted photos are available under the same CC BY-SA licence'). CC0 and Public domain need no credit, but we credit them anyway for consistency.
